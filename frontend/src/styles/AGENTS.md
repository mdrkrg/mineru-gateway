- Use StyleX exclusively: no utility classes and no stylesheets besides `reset.css`; declare every `stylex.create` object at module scope.
- In Solid use `stylex.attrs()`, never `stylex.props()` or `sx` (`sxPropName` is off); spread it for elements and take `.class` for styled components and library primitives, and never put `class` or `style` next to an `attrs` spread.
- Shared values come from `tokens.stylex.ts` (`defineConsts`): never hardcode palette or scale values or import non-StyleX constants into a style object; scale tokens use `rem` so browser font-size preferences keep working, while `1px` borders stay in `px`.
- Before adding a local style block, reuse the shared modules: `typography` (body, meta, headings), `layout` (page widths, stacks, rows, flex and spacing helpers), `controls` (inputs, buttons, links, alert surfaces), `actions` (text and compact actions, clear affordances, disabled opacity), `forms` (form rows, medium inputs, checkbox labels), `table` (tables, cells, row dividers, truncation), `badges` (status and API-key pills), `feedback` (success surfaces and text), `modal` (dialog and overlay chrome), `icons` (`xs`/`sm`/`md`/`lg`), and `auth` (OAuth loading and divider); local blocks are only for genuine one-off geometry.
- Button hover variants use `:hover:not(:disabled)`, not `:enabled:hover`, so the same variant works when a `Link` is styled as a button; focus rings use `outline` rather than `box-shadow` for forced-colors support.
- The reset lives in the `reset` layer, ordered before `stylex.priority*` through `useCSSLayers` in `vite.config.ts`.
